2. Django Channels मध्ये Consumer म्हणजे काय? (सविस्तर मराठीत)
तुम्ही Python Backend Developer आहात, त्यामुळे आपण हे Django DRF च्या उदाहरणातून समजून घेऊ.
A. सर्वात आधी Consumer ची गरज का पडते?
समजा आपण Django DRF वापरून एक Chat Application बनवले.

आपल्याकडे खालील API आहे:
@api_view(["POST"])def send_message(request):    message = request.data.get("message")    return Response({        "message": message    })



आता Rohit ने Amit ला message पाठवला.

काय होईल?
1. React कडून Django API ला HTTP Request जाईल.
2. Django तो Request process करेल.
3. Django Response पाठवेल.
4. Request-Response पूर्ण होईल.
पण समजा Amit ला Rohit ने पाठवलेला message लगेच दाखवायचा आहे.

त्यासाठी आपल्याला पुन्हा API Call करावी लागेल किंवा Polling वापरावे लागेल.

इथेच WebSocket उपयोगी पडते.

WebSocket मध्ये एकदा Connection तयार झाल्यानंतर दोन्ही बाजू एकमेकांना कधीही Message पाठवू शकतात.

पण Django ला हे Connection आणि Messages व्यवस्थित Handle करण्यासाठी एका Mechanism ची गरज आहे.

त्यासाठी Django Channels मध्ये आपण Consumer वापरतो.
B. Consumer म्हणजे नेमके काय?
सोप्या भाषेत:

Consumer हा Django Channels मधील एक Python Class आहे, जो WebSocket Connection ची संपूर्ण Lifecycle Handle करतो.

म्हणजे:
- User WebSocket ला Connect झाला तर काय करायचे?
- User ने Message पाठवला तर काय करायचे?
- User Disconnect झाला तर काय करायचे?
- Message इतर Users पर्यंत कसा पाठवायचा?
हे सर्व काम Consumer करतो.

उदाहरणार्थ:
Consumer चे काम
React Frontend

User connects / sends message


Django Channels Consumer
1. connect()

2. receive()

3. disconnect()



Other Connected Users

Receive real-time messages


C. Consumer चे तीन महत्त्वाचे Methods
Django Channels मध्ये तीन Methods खूप महत्त्वाचे आहेत.
1. connect()
जेव्हा React मधून WebSocket Connection तयार होते, तेव्हा Django मधील connect() Method execute होते.

उदाहरण:
class ChatConsumer(AsyncWebsocketConsumer):    async def connect(self):        print("User Connected")        await self.accept()



React मधून:
const socket = new WebSocket(
    "ws://localhost:8000/ws/chat/1/"
);


आता काय होईल?
1. React WebSocket Connection Request पाठवेल.
2. Django Channels URL तपासेल.
3. संबंधित Consumer execute होईल.
4. connect() Method Call होईल.
5. await self.accept() Connection स्वीकारेल.
महत्त्वाचे: accept() केल्याशिवाय WebSocket Connection स्वीकारले जात नाही.
2. receive()
जेव्हा React कडून Django ला Message पाठवला जातो, तेव्हा Consumer मधील receive Method execute होते.

उदाहरण:
async def receive(self, text_data):    print("Message Received")    print(text_data)



React:
socket.send(
    JSON.stringify({
        message: "Hello Rohit"
    })
);


Django ला खालील JSON मिळेल:
{
    "message": "Hello Rohit"
}


Consumer त्या Message वर Processing करू शकतो.

उदाहरणार्थ:
- Message Validate करणे.
- Database मध्ये Save करणे.
- दुसऱ्या User ला Message पाठवणे.
तुम्ही AsyncJsonWebsocketConsumer वापरत असाल तर receive_json() Method वापरू शकता. त्यामध्ये JSON आधीच Python Dictionary मध्ये convert केलेला असतो.
3. disconnect()
जेव्हा User Browser बंद करतो किंवा WebSocket Connection बंद होते, तेव्हा disconnect() Method execute होतो.
async def disconnect(self, close_code):    print("User Disconnected")



याचा उपयोग:
- User Offline दाखवणे.
- Redis मधील Connection Tracking Update करणे.
- Channel Group मधून User काढणे.
- Resources Cleanup करणे.

समजा आपल्या Chat Application मध्ये दोन Users आहेत.

connect → receive → save → broadcast

Rohit ने पाठवलेला Message Amit ला लगेच मिळतो.
यासाठी Consumer Code:
from channels.generic.websocket import AsyncWebsocketConsumerimport jsonclass ChatConsumer(AsyncWebsocketConsumer):    async def connect(self):        self.room_group_name = "chat_room_1"        await self.channel_layer.group_add(            self.room_group_name,            self.channel_name        )        await self.accept()    async def receive(self, text_data):        data = json.loads(text_data)        message = data["message"]        await self.channel_layer.group_send(            self.room_group_name,            {                "type": "chat_message",                "message": message            }        )



E. आता या Code मधील महत्त्वाचे Concepts समजून घेऊ
1. self.channel_name म्हणजे काय?

प्रत्येक WebSocket Connection ला Django Channels एक Unique Channel Name देते.

उदाहरण:
Rohit  → specific.channel.abc
Amit   → specific.channel.xyz
Priya  → specific.channel.pqr


प्रत्येक User चे Connection वेगळे असते.

2. group_add() म्हणजे काय?
await self.channel_layer.group_add(    self.room_group_name,    self.channel_name)



याचा अर्थ:

सध्याच्या User चे WebSocket Connection एका Group मध्ये Add करणे.

उदाहरण:
chat_room_1

    |
    |---- Rohit
    |
    |---- Amit
    |
    |---- Priya


3. group_send() म्हणजे काय?
await self.channel_layer.group_send(    self.room_group_name,    {        "type": "chat_message",        "message": "Hello everyone"    })



याचा अर्थ:

या Group मधील सर्व Connected Users ना Event पाठवणे.

4. chat_message() म्हणजे काय?
async def chat_message(self, event):    await self.send(        text_data=json.dumps({            "message": event["message"]        })    )



जेव्हा group_send() मध्ये:
"type": "chat_message"



असे दिले जाते, तेव्हा Django Channels Consumer मधील chat_message() Method Execute करतो.

हा Channels चा Event Dispatching Mechanism आहे.

F. Consumer आणि DRF View मधील फरक
हा Interview साठी खूप महत्त्वाचा प्रश्न आहे.
Django DRF View	Django Channels Consumer
HTTP Request Handle करतो	WebSocket Connection Handle करतो
GET, POST, PUT	connect, receive, disconnect
Request-Response	Persistent Connection
API Response देतो	Real-time Event पाठवतो
DRF permissions वापरतो	स्वतः WebSocket authorization करतो

G. Sync Consumer vs Async Consumer
Django Channels मध्ये दोन महत्त्वाचे प्रकार आहेत.
प्रकार	Class
Synchronous	WebsocketConsumer
Asynchronous	AsyncWebsocketConsumer

उदाहरण:
from channels.generic.websocket import WebsocketConsumerclass MyConsumer(WebsocketConsumer):    def connect(self):        self.accept()



Async Example:
from channels.generic.websocket import AsyncWebsocketConsumerclass MyConsumer(AsyncWebsocketConsumer):    async def connect(self):        await self.accept()



Async Consumer मध्ये await वापरून asynchronous operations करता येतात.

उदाहरणार्थ Redis Channel Layer सोबत काम करताना:
await self.channel_layer.group_send(...)



पण Django ORM सारख्या synchronous operations थेट Async Consumer मध्ये चालवू नयेत. त्यासाठी database_sync_to_async वापरा किंवा योग्य asynchronous ORM API वापरा.

H. Interview मध्ये Consumer बद्दल कसे सांगायचे?
Interview-ready answer
Question: What is a Consumer in Django Channels?

"A Consumer is a Python class in Django Channels that handles WebSocket connections and messages. It manages the connection lifecycle using methods like connect, receive and disconnect. We can also use channel layers and Redis to broadcast messages to multiple connected users in real time."

मराठीत अर्थ:

Consumer हा Django Channels मधील Python Class आहे. तो WebSocket Connection तयार करणे, Message Receive करणे, दुसऱ्या Users ना Message पाठवणे आणि Connection बंद करणे ही सर्व कामे करतो.
